# ReplyOne

AI powered Chrome extension that generates replies for social media posts.

## What it does

ReplyOne helps you generate replies for social media posts using AI. It reads the post context and generates a relevant reply that you can edit before posting.

## How to use

Clone the repository and open Chrome extensions.

Click Load unpacked and select the project folder.

Open a social media post and use ReplyOne to generate a reply.

## Built with

JavaScript, HTML, CSS, Chrome Extension APIs and AI.
